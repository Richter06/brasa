# BRASA

Modelo de vitrine da Rouxinol para um restaurante fictício de cozinha brasileira contemporânea.

Direção:
- preto carvão
- laranja brasa
- creme quente
- fotografia e vídeo como protagonistas
- interface mínima
- refinado, mas amigável

Fluxo:
Hero → Intro → Signature Dishes → The Kitchen → Menu → Experience → Restaurant → Story → Reservation → Footer
